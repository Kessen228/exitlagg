# Планировщик лаунчеров

Программа для Windows, которая открывает игровые лаунчеры (Steam, Epic Games, EA app, Ubisoft Connect,
Battle.net и другие) по расписанию и закрывает их через заданное время. Например, каждую ночь в 04:00
на 2 часа, чтобы лаунчеры скачали обновления игр, пока вы спите.

## Возможности

- Расписание по времени и дням недели: каждый день, будни, выходные или любые выбранные дни.
- Время работы для каждой задачи: по его истечении лаунчеры закрываются. Можно выбрать «Не закрывать».
- Одна задача может запускать сразу несколько лаунчеров, с паузой между ними.
- Автоматический поиск установленных лаунчеров: Steam, Epic Games Launcher, EA app, Ubisoft Connect,
  Battle.net, GOG GALAXY, Rockstar Games Launcher, Riot Client, Lesta Игровой центр,
  Wargaming.net Game Center, VK Play, Amazon Games. Любой другой лаунчер можно добавить вручную.
- Штатное закрытие (у Steam — командой `-shutdown`). Если лаунчер не закрылся за отведённое время,
  программа завершает его процессы принудительно — только процессы самого лаунчера, без дочерних.
- Лаунчер, который вы открыли сами до начала задачи, программа не закрывает.
- Если в момент закрытия за компьютером кто-то работает или играет, закрытие откладывается,
  пока компьютер не освободится.
- Если компьютер был выключен в момент запуска, а время работы задачи ещё не вышло,
  задача запустится, как только запустится программа.
- Запуск вместе с Windows, работа в фоне со значком в области уведомлений, журнал всех действий.

## Перед использованием

1. **Авторизуйтесь во всех лаунчерах, где это нужно.** Откройте каждый лаунчер вручную, войдите в аккаунт
   и отметьте «Запомнить меня». Иначе при запуске по расписанию лаунчер остановится на окне входа
   и ничего не скачает.
2. **Включите автоматическое обновление игр** в настройках каждого лаунчера. В Steam также проверьте,
   что в «Настройки → Загрузки» нет ограничения времени загрузок, а в свойствах игр выбрано
   автоматическое обновление.
3. **Включите «Запускать вместе с Windows»** на вкладке «Настройки». Задачи выполняются, только пока
   программа запущена. Компьютер в это время должен быть включён и не находиться в спящем режиме.

## Установка

**Готовый exe.** Откройте вкладку [Actions](https://github.com/Kessen228/exitlagg/actions) репозитория, выберите последнюю успешную
сборку «Сборка» и скачайте артефакт `LauncherScheduler` (внутри — `LauncherScheduler.exe`). Для версий
с тегом `v*` exe также прикладывается к [релизу](https://github.com/Kessen228/exitlagg/releases). Установка не нужна: положите exe
в удобную папку (например, `C:\Program Files\LauncherScheduler` или `Документы`) и запустите.

**Из исходников.** Нужен [Python](https://www.python.org/downloads/) 3.10 или новее.

```bat
pip install -r requirements.txt
pythonw main.py
```

**Собрать exe самостоятельно** — запустите `build.bat`. Готовый файл появится в `dist\LauncherScheduler.exe`.

## Как пользоваться

1. При первом запуске программа сама найдёт установленные лаунчеры. Их список — на вкладке «Лаунчеры».
   Там же можно добавить лаунчер вручную («Добавить…» → шаблон или путь к `.exe`) и проверить
   его кнопками «Запустить» и «Закрыть».
2. На вкладке «Расписание» нажмите «Добавить…» и укажите время запуска, дни недели, сколько лаунчеры
   должны проработать и какие лаунчеры запускать.
3. Кнопка «Запустить сейчас» выполняет выбранную задачу сразу, не дожидаясь расписания.
4. Крестик окна сворачивает программу в область уведомлений. Чтобы выйти, щёлкните значок правой
   кнопкой мыши → «Выход».

### Параметры лаунчера

| Поле | Назначение |
|---|---|
| Программа | Путь к `.exe` (или ярлыку `.lnk`) лаунчера. |
| Параметры запуска | Например, `-silent`: Steam и Epic Games запустятся свёрнутыми в трей. |
| Процессы | Имена процессов через запятую. По ним программа узнаёт, что лаунчер запущен, и закрывает его. Можно указать полный путь к exe, если имя процесса неоднозначное (например, `Launcher.exe` у Rockstar). |
| Команда закрытия | Параметры для штатного закрытия, например `-shutdown` у Steam. Если поле пустое, программа закрывает окно лаунчера, а затем, если нужно, завершает процессы. |

### Настройки

- **Не закрывать лаунчеры, которые были открыты до начала задачи.** Если вы сами пользуетесь лаунчером,
  программа его не закроет.
- **Запускать пропущенные задачи.** Догоняющий запуск, если программа была закрыта или компьютер был
  выключен в момент начала задачи.
- **Откладывать закрытие, пока за компьютером кто-то работает.** Лаунчеры закроются только после
  указанного числа минут без активности клавиатуры и мыши.
- **Пауза между запуском лаунчеров** и **ожидание штатного закрытия** перед принудительным.

Настройки, состояние и журнал (`app.log`) хранятся в `%APPDATA%\LauncherScheduler`.

## Если что-то не работает

- **Лаунчер не закрывается, в журнале «нет прав».** Лаунчер запущен от имени администратора.
  Запустите программу тоже от имени администратора или отключите для лаунчера запуск от имени администратора.
- **Лаунчер открылся, но обновления не скачались.** Проверьте, что вы вошли в аккаунт, что автообновление
  включено и что время работы задачи достаточно для загрузки.
- **Задача не запустилась.** Программа должна быть запущена в это время (значок в трее), компьютер не должен
  спать. Подробности в журнале.

## Для разработчиков

```bash
pip install psutil
python -m unittest discover -s tests -t .
```

Структура: `launcher_scheduler/scheduler.py` (логика запуска и закрытия), `schedule.py` (расчёт времени),
`processes.py` (работа с процессами), `presets.py` (известные лаунчеры и их поиск), `gui.py` (окно на tkinter).
Иконка генерируется скриптом `tools/make_icon.py`.
